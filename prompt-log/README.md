# Prompt Log

One file per logged Claude Code interaction, named `YYYY-MM-DD-<author>-<short-topic>.md`.
See `AI_USAGE_GUIDELINES.md` section 2 for when an entry is required.

## Entry template

```markdown
# <short topic>
- Date:
- Author:
- Tool / model: Claude Code / <model>
- PR: <link>

## Prompt
<the prompt(s) you gave>

## Output summary
<what Claude Code produced or did>

## Outcome
- Kept:
- Changed:
- Rejected (and why):
```
