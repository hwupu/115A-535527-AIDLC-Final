# 醫院檢傷問診病人查核表

> Converted from `醫院檢傷問診病人查核表.docx` (text only; the source had no tables or images).

## 一、 主要問題流程

- **TOCC 篩檢：** 優先確認感染風險，旅遊史(Travel history）、職業(Occupation)、接觸史(Contact history)、群聚史(Cluster)。
- **生理量測評估：** 確認量測禁忌（如：不可量血壓/打針之患側），隨後進行生理徵象測量。
- **主訴深度詢問：** 針對病患本次不舒服的原因進行詳細了解。
- **護理專業評斷：** 提交資訊給護理師判斷主訴與檢傷級數。
- **行政動線引導：** 引導病患至掛號區完成手續。

## 二、 實際問的問題

- 請問目前有發燒、咳嗽或感冒症狀嗎？
- 過去兩個月內，有去過國內或國外旅遊嗎？
- 請問您的兩隻手都可以量血壓嗎？
  - (註：若病患表示某處不能觸碰，請立即戴上「禁止治療」手圈，並針對可量測處測量血壓、血氧等)
- 請問這次是哪裡不舒服來掛急診呢？
  - (後續針對病患回答之問題進行深度詢問)

## 三、 其他問題

- 請問您的出生年月日是？
- 請問今天有家屬陪同過來嗎？
- 您目前走路可以嗎？還是需要幫您安排輪椅？
