# External user testing protocol - not yet conducted

Two external-user sessions are required for CP2 design rationale. The two CP1 interviews are discovery evidence, not prototype tests. Recruit representative nurses/physicians with consent, no patient data. Do not invent findings. These forms are blank templates and must remain marked NOT CONDUCTED until actual sessions occur.

## Session form (repeat once for each session)

- Status: NOT CONDUCTED
- Anonymous code / role / outside-team confirmation:
- Date / facilitator / consent to participation and any recording:
- Software revision / prompt / model / scenario:
- Baseline task: paper note then input into a simulated record; tool task: same complexity, different fictional case. Alternate method order across participants.
- Baseline time, tool time, errors, clarifying questions: NOT MEASURED
- Difficulty observed / exact behavior / needed assistance:
- Participant feedback (actual, anonymized):
- Design change proposed / implemented / retest outcome:
- Evidence file and limitations:

## Task

Use a fictional fever/cough case. Nurse obtains history and measured vitals, reviews each draft and confirms. Physician reads the confirmed handoff, identifies onset and TOCC, and records any question still needed. Use the same stopping rule for both methods: complete, readable handoff ready for the physician. Exclude no failed task without reporting it. Stop on participant request.

## Measures

Report raw times per participant, median/range and `(baseline-tool)/baseline`. Separately report incorrect/missing fields, editing burden and repeated handoff questions. No statistical significance claims with this small sample. Do not mix machine inference latency with human task time. If model failure forces manual entry, include that time.
