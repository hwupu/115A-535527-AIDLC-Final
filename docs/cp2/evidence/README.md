# Machine evidence snapshot (2026-11-04)

These UTF-8 JSON/JSONL files are the actual local-run outputs documented in the report. Browser tests automate fictional roles; STT inputs were generated by Windows Hanhan. No external-user study or clinical outcome is represented.

- checks.json: 11 command checks, all exit zero.
- browser-tests.json: five browser tests, including independent contexts, two tablet sizes, actual Qwen extraction and synthetic microphone through Whisper.
- prompt-v2.jsonl / prompt-v3.jsonl: all twelve development cases, raw outputs and failures; v2 4/12 and v3 8/12 whole-case passes. Empty case skips inference.
- stt-synthetic.json / stt-base.json / stt-small.json: tiny/base/small on one fictional TTS clip.
- model-manifest.json: actual downloaded snapshot identifiers and file hashes; weights are not committed.
- clean-extraction.json: clean source extraction verification using existing Python dependency environments and offline pnpm cache; archive hash refers to the snapshot tested then, not any later regenerated ZIP.

The snapshots predate publication. Phrases such as `uncommitted`, local paths and old archive hashes describe that run and must not be edited to pretend that it ran on a later GitHub commit. Runtime logs, screenshots, audio, PDF, model weights and database remain local. The audio fixture can be regenerated with scripts/make-synthetic-audio.ps1.
