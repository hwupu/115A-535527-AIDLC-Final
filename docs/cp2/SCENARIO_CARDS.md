# 使用者測試情境卡（列印用）

來源：`docs/SCENARIOS.md` 的 S01、S03、S04。**病人、日期與細節全部是虛構的。** SCENARIOS 仍是 AI 起草、待護理師確認的版本，參考答案如有疑義以護理師意見為準。
流程見 [`USER_TEST_PROTOCOL.md`](USER_TEST_PROTOCOL.md)，表單見 [`USER_TEST_FORM.md`](USER_TEST_FORM.md)。

每個情境三張，分開列印：
- **扮演者卡**：給扮演病人的組員。護理師問到什麼就照卡片回答，**卡片上沒有的一律回答「不知道」或「沒有」，不要臨場編**。
- **量測值卡**：給主持人。護理師說要量血壓、體溫等時，由主持人念出數值（測試時沒有真的量）。
- **參考答案**：給主持人對照 AI 草稿，**不要給護理師看**。

## S01 流感樣症狀｜扮演者卡

**你是：** 28 歲國小老師，自己一個人走進來。

| 護理師問到 | 你的回答 |
|---|---|

| 什麼時候開始 | 昨天晚上開始發燒。 |
| 發燒、咳嗽、感冒症狀 | 有，昨天晚上開始發燒，今天早上在家量耳溫三十八度四，還有咳嗽，喉嚨很痛。 |
| 有沒有喘、胸悶 | 沒有。 |
| 兩個月內國內外旅遊 | 沒有，我都在新竹。 |
| 職業 | 國小老師。 |
| 接觸類似症狀的人、群聚 | 有，我們班這個禮拜有四、五個小朋友請病假，聽說是流感。 |
| 兩隻手可以量血壓嗎 | 都可以。 |

| 有家屬陪同嗎 | 沒有，我自己來。 |

## S01｜量測值卡（主持人）

血壓 **122／80**，脈搏 **92**，血氧 **97**，耳溫 **38.5**。（病人在家量的 38.4 不是這次的量測值）

## S01｜參考答案（不要給護理師看）

- 主訴：發燒、咳嗽、喉嚨痛；發作：昨天晚上；伴隨：全身痠痛、咳嗽有痰、吞嚥痛；吃退燒藥無效
- TOCC：發燒咳嗽感冒 有；旅遊 無；職業 國小老師；接觸 有；群聚 有
- 量測禁忌：無（兩手都可以）
- 生命徵象：血壓 122／80、脈搏 92、血氧 97、體溫 **38.5**（不是 38.4）
- 出生日期 1998-05-14；陪同 無；行動 步行
- 檢傷級數：只由護理師決定，AI 不應出現任何級數

| 平常週幾洗腎 | 一三五。 |

## S03｜量測值卡（主持人）

血壓（**右手**）**158／92**，脈搏 **88**，血氧 **93**。

## S03｜參考答案（不要給護理師看）

- 主訴：呼吸喘、下肢水腫；今天喘到走不動，平躺較喘；昨天沒洗腎（平常週一三五）
- TOCC：發燒 無、咳嗽 有（輕微）；旅遊 無
- 量測禁忌：**左手**（洗腎瘻管）；需戴「禁止治療」手圈；血壓量**右手**
- 生命徵象：血壓 158／92、脈搏 88、血氧 93
- 相關病史：血液透析；出生日期 1958-03-09；行動 輪椅
- 陪同：兒子（在停車，當下不在場）—— 不應簡化成「有人陪」就好，記錄方式可問護理師意見
- 檢傷級數：只由護理師決定，AI 不應出現任何級數
